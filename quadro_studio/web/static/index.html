Quadro Print Studio

One model in. Four heads at work.

Turn a single sliced model into a multi-head print for your Quadro. Everything runs on this computer; nothing is sent to your printer.

Modes

Farm Mode

Available

Many identical copies of one single-colour model, printed by four synchronized heads.

Copy Mode

Available

Two copies at once: T0 prints the left one, T1 the right one; T2 and T3 stay parked.

Dual Color Copy Mode

Available

Two two-colour models at once: T0 + T1 print colour 1 on both, then T2 + T3 print colour 2.

        Good to know

        • The layout is calculated from your model's size and your printer's measured bed. Bigger models fit fewer copies; models are never scaled.
        • The first layers are printed by each head on its own, so every head starts exactly on the measured bed (Farm and Copy: layers 1–5, Dual Color: layers 1–3). After that the heads print together.
        • Dual Color Copy Mode needs a four-tool slice with two identically coloured models, and tool offsets that let both pairs print both models at one shared height and Y. If they don't, the layout shows why and no file is made.
        • Every file is checked by a separate verification step before it can be downloaded. Passing these software checks does not mean the file was tested on your printer.
