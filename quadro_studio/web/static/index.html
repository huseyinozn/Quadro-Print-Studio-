Quadro Print Studio

One model in. Four heads at work.

Turn a single sliced model into a print for all four heads of your Quadro. Everything runs on this computer; nothing is sent to your printer.

Farm Mode

  1. The ZIP of your Quadro's current configuration, including the saved bed mesh and tool offsets.

  2. G-code of one single-colour model from Co Print Slicer, sliced once for T0.

  3. A multiple of 4: each of the four heads prints the same number of copies.

        Good to know

        • The layout is calculated from your model's size and your printer's measured bed. Bigger models fit fewer copies; models are never scaled.
        • Layers 1–5 are printed by each head on its own, so every head starts exactly on the measured bed. From layer 6 on, all four heads print together.
        • Every file is checked by a separate verification step before it can be downloaded. Passing these software checks does not mean the file was tested on your printer.
